# Question 2 — Upload a File to Blob Storage

## Scenario

The storage account and its `data` container already exist — `setup.bash`
provisioned them. Now put a file in it: as the cloud administrator, **upload a
file to the `data` container** so the team can share it.

## Requirements

| # | Requirement | Value |
|---|-------------|-------|
| 1 | A storage account + `data` container | in `lab-storage-blob02-rg` (setup did this) |
| 2 | A **blob** exists in the `data` container | named `hello.txt` |

> The storage account name was generated by setup. Find it with
> `az storage account list -g lab-storage-blob02-rg --query "[0].name" -o tsv`.

## Work the question

```bash
./setup.bash      # provisions the account + container, prints the target
# ... upload a file yourself (see solution.md if you get stuck) ...
./validate.bash
./cleanup.bash
```
